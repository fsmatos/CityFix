# Tasks

Put one Markdown file per task here (for example `login-screen.md`). Each file is the spec the planner reads. Include the goal, the relevant section of the brief, and any acceptance checks you already know. Task IDs are per person: `F-001`, `F-002` on `dev/Francisco`; `D-001`, `D-002` on `dev/Diogo`.

Start one with `/feature-dev <file-name>`.

## Phase 1 (model + base UI)

The 12 phase 1 tasks (D-001..D-006 for Diogo, F-001..F-006 for Francisco) are in [`phase-1/`](phase-1/README.md), with dependencies and a suggested order. Start one with `/feature-dev phase-1/F-001-theme-and-strings`.
